# Evidências para avaliação técnica

O [README original](challenge/README.original.md) define os requisitos. O [relatório da Fase 9](PHASE_9_FINAL_REPORT.md) registra a execução desta revisão. Use Bun 1.4.4 e Docker Compose com o daemon local disponível.

```sh
bun install --frozen-lockfile
bun run demo:complete
bun run verify:evidence
bun run test:soak
bun run test:mutation
```

Demo, verificação e soak criam projetos Compose independentes com portas dinâmicas em loopback. Para exportar a evidência em JSON, defina `PHASE9_EVIDENCE_DIR` antes de rodar os comandos. A suite de mutação usa uma cópia temporária e imprime seu JSON no terminal. [Harness](../scripts/validation/phase9.ts)
