# Domínio financeiro

O domínio contém objetos de valor, entidades, aplicação de transações sobre a carteira, ledger, inbox, outbox e eventos. Os tipos dependem de TypeScript e de APIs padrão.

Use `openWallet` em `wagering/open-wallet.ts` para coordenar a abertura e `WagerTransaction.apply` para executar operações de aposta. As regras, transições e responsabilidades futuras estão no [modelo de domínio](../../docs/DOMAIN_MODEL.md).
